FREE FLIGHT — image slots
=========================

The pitch page renders fully on its own (every card has a generated SVG
illustration). To swap in real product photos, save an image into THIS
folder with the exact filename below. No code changes needed — each <img>
falls back to its SVG art if the file is missing.

enversed.jpg        https://enversedstudios.com/en/portfolio/vr-paragliding/      the VR paragliding rig

Note: these were NOT auto-downloaded — this build environment blocks
outbound file downloads (network allowlist) and the sites refuse bots,
so images must be added from a normal browser. Use only with proper
credit / permission in any public-facing version of the pitch.
